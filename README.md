# Group7Project
Group 7: Dylan, Omar, Richard
Topic- Ethics of Animal Testing
Purpose: This site’s goal is to raise awareness of animal testing as well as its downsides/impact on lab animals, as well as its purpose in testing things such as medicine. We aim to highlight the ethics involving testing on animals as well as alternatives to testing on animals.
